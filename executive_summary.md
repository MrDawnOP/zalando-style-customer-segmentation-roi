# Executive Summary

## Project Context
This project analyses a fictional European fashion e-commerce company similar to Zalando. The goal is to improve marketing ROI, customer retention and budget allocation using customer, order and campaign data.

## Commercial Performance Snapshot
| Metric | Value |
|---|---:|
| Total revenue | €4,312,794 |
| Total profit | €1,543,955 |
| Profit margin | 35.8% |
| Orders | 50,000 |
| Return rate | 11.2% |
| Net revenue after returns | €3,787,717 |
| Marketing spend | €3,425,472 |
| Overall ROAS | 1.26 |
| Overall ROI | 0.26 |

## Key Findings
1. Retention and high-intent channels outperform broad acquisition. Email delivered the strongest ROAS, while Display Ads showed the weakest ROI.
2. Customer value is concentrated. High-Value Customers generated the largest revenue contribution.
3. Returns are a material profitability risk. Dresses had the highest return rate.
4. Paid social requires tighter governance because traffic volume does not always equal conversion quality.
5. Budget should move toward profitable retention and high-intent acquisition channels.

## Recommended Actions
| Priority | Recommendation | Expected Impact |
|---|---|---|
| 1 | Increase high-ROAS lifecycle and high-intent spend | Higher profitable revenue and lower blended CPA |
| 2 | Reduce high-spend low-conversion campaigns | Protect marketing budget from waste |
| 3 | Launch retention journeys for At-Risk customers | Improve repeat purchase and reduce churn |
| 4 | Personalise offers for Champions and Loyal Customers | Increase CLV without excessive discounting |
| 5 | Monitor return-heavy categories weekly | Improve margin and reduce net revenue leakage |
| 6 | Build a monthly executive dashboard | Improve decision speed and accountability |

## Risks
- Synthetic data is for portfolio demonstration and should not be treated as real Zalando data.
- Attribution is simplified to campaign-level attribution.
- Churn-risk scoring is rules-based; a production version should test predictive modelling.
